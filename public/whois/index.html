关于 WHOIS 查询

WHOIS 和 RDAP 有什么区别？

WHOIS 是 1980 年代沿用至今的明文查询协议；RDAP 是 ICANN 主推的新一代注册数据协议，返回结构化 JSON、数据更规范。本工具优先走 RDAP 直连各注册局官方接口，注册局未提供 RDAP 时自动切换传统 WHOIS（43 端口），两条通道互为备份。

为什么有些域名看不到注册人信息？

受 GDPR 等隐私法规影响，多数注册局与注册商已对个人注册信息做隐私保护（Redacted for privacy），仅保留注册商、日期、DNS、状态等技术信息，这是正常现象。

域名状态代码是什么意思？

常见如 clientTransferProhibited（注册商转移锁，正常保护）、serverDeleteProhibited（注册局删除锁）、clientHold（暂停解析，异常状态）、pendingDelete（等待删除，即将掉出）。查询结果中的状态徽章会给出中文说明，红色代表需要注意。

数据来自哪里？多久更新？

域名数据直连各注册局（Verisign、CNNIC、DENIC 等）官方 RDAP / WHOIS 接口；IP 与 ASN 数据来自五大区域互联网注册机构（ARIN / RIPE / APNIC / LACNIC / AFRINIC）。
