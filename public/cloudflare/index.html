Cloudflare 节点检测能看出什么

全球超过五分之一的网站前面都挂着 Cloudflare。你打开这些网站时，请求并不是直接到达网站服务器，而是先到 Cloudflare 离你最近的边缘节点（数据中心，Cloudflare 内部称 colo），再由边缘节点回源。命中哪个节点，直接决定了打开速度、视频是否卡顿、以及某些服务把你识别成哪个地区的用户。本页向 Cloudflare 的 cdn-cgi/trace 接口发一次请求，把返回的节点代码、出口 IP、WARP 状态、协议版本翻译成人能看懂的结论。

风险指数怎么算

Cloudflare 企业版 Bot Management 的机器人分数不对外公开，本页的风险指数是本站的等效评估：以出口 IP 在多个商业情报源的信誉评分为基础，叠加公开代理、住宅代理、企业代理、VPN、Tor、机房 IP、滥用记录七类高置信信号，再结合 WARP 等 Cloudflare 连接特征。数值越小越好；60 以上通常意味着访问 Cloudflare 站点时容易遇到人机验证或拦截。想看更细的评分依据，可以打开 IP 评分页。

人机验证结果怎么看

  • 无感自动通过：Turnstile 不需要任何操作就完成校验，说明 Cloudflare 对当前浏览器与网络的信任度高，是最理想的结果。
  • 需要点击验证：托管模式弹出了「确认你是人类」的勾选框，点一下即可通过。环境整体正常，但存在少量可疑特征。
  • 无法通过：即使点击也校验失败，通常是浏览器指纹异常、自动化特征明显或 IP 信誉较差，访问很多站点会反复遇到验证码。

三种常见的异常场景

  • 人在亚洲，节点在美国：免费版 Cloudflare 站点从中国大陆、部分东南亚线路出发时，经常被调度到 LAX、SJC 这类远端节点，延迟从几十毫秒变成两百毫秒以上。对比表里「本站（免费版）」与「企业版」两行如果命中不同节点，就是这种情况。
  • 出口 IP 与首页不一致：说明你的代理或分流规则把 Cloudflare 流量单独处理了。配合首页的分流测试可以核对规则是否按预期生效。
  • WARP 显示已开启：出口 IP 变成 Cloudflare 自己的地址（AS13335）。这类 IP 在 ChatGPT、Claude 等服务的风控里评分偏低，注册和登录更容易被拦。

常见问题

什么是 Cloudflare 边缘节点（colo）？

Cloudflare 在全球 135 个国家和地区部署了 342 个数据中心，每个数据中心用三字母机场代码标识（如 HKG 香港、NRT 东京、SIN 新加坡、LAX 洛杉矶）。你访问任何接入 Cloudflare 的网站时，请求先到达离你网络最近的边缘节点，再回源到网站服务器。本页读取 Cloudflare 的 cdn-cgi/trace 接口，把你命中的节点代码翻译成城市并标出国家。

为什么免费版和企业版网站命中的 Cloudflare 节点不一样？

Cloudflare 对不同套餐使用不同的网络策略。免费版和 Pro 版的流量在部分地区（尤其是从中国大陆、部分东南亚线路出发时）会被调度到成本更低的远端节点，例如美国西海岸的 LAX、SJC；企业版和 Cloudflare 自家服务（1.1.1.1、cloudflare.com、speed.cloudflare.com）则更容易命中 HKG、NRT、SIN 这类就近节点。本页把同一条线路下不同等级站点命中的节点和延迟并排展示，差异一目了然。

Cloudflare 出口 IP 和普通出口 IP 有什么区别？

普通出口 IP 是你直连网站时对方看到的地址；Cloudflare 出口 IP 是你访问接入 Cloudflare 的网站时，Cloudflare 边缘节点记录到的地址。如果你的代理或分流规则把 Cloudflare 流量单独处理，两者会不同。本站首页的分流测试和本页的出口 IP 都能帮你确认规则是否生效。

WARP 是什么？检测结果里 warp=on 和 warp=plus 是什么意思？

WARP 是 Cloudflare 提供的加密隧道服务，开启后你的流量先进入 Cloudflare 网络再出去。warp=off 表示未使用 WARP；warp=on 表示使用免费版 WARP；warp=plus 表示 WARP+ 付费版。开启 WARP 时，出口 IP 会变成 Cloudflare 的地址（AS13335），很多网站对这类 IP 的风控更严格。

延迟多少算正常？

命中同城或同区域节点时，浏览器到 Cloudflare 边缘的往返延迟通常在 5 到 60 毫秒；跨海到美国西海岸约 120 到 200 毫秒；超过 300 毫秒多半是线路绕行或节点被调度到了远端。本页延迟为浏览器实际发起请求的耗时，会略高于纯网络 RTT，用于横向对比不同网络等级最合适。

HTTP/3 和 TLS 1.3 显示未启用怎么办？

HTTP/3 基于 QUIC（UDP 443），浏览器通常在第二次访问同一站点时才会切换到 HTTP/3；如果一直显示 HTTP/2，可能是代理或防火墙不放行 UDP 443。TLS 1.3 是当前标准，现代浏览器默认支持，显示 TLS 1.2 一般意味着中间有代理在做 TLS 降级或流量审计。

Turnstile 无感通过和需要点击有什么区别？

Turnstile 是 Cloudflare 的人机验证。非交互模式完全在后台校验；托管模式由 Cloudflare 根据浏览器指纹、网络信誉和行为特征决定是否弹出勾选框。无感通过说明 Cloudflare 高度信任当前环境；需要点击说明存在少量可疑特征；点击后仍失败说明环境风险较高，访问接入 Cloudflare 的网站会频繁遇到验证甚至被拦。本页的 token 会送到本站服务器做二次校验，显示 PASS 才算真正通过。

风险指数是 Cloudflare 官方给的吗？

不是。Cloudflare 企业版 Bot Management 的机器人分数只对企业客户开放，本页的风险指数是本站基于多个商业 IP 情报源的信誉评分、七类代理特征和 WARP 等 Cloudflare 连接特征计算的等效评估，与 Turnstile 的实测结果互相印证。

这个页面会记录我的 IP 吗？

不会。所有检测都由你的浏览器直接向 Cloudflare 接口发起，节点历史只保存在浏览器本地存储，本站服务器不记录查询记录。
